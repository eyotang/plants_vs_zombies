## 本地运行

macOS 双击 `本地启动.command`，保持终端窗口打开；关闭窗口会停止本地服务。所有游戏文件均在本地，不需要安装 Node 或下载素材。

也可以运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

然后访问 http://127.0.0.1:8080 。完整版本使用模块和本地资源请求，需要通过本地服务打开。源码根目录的 `index.html` 仍可直接双击游玩五关参考挑战。

## 冒险与道具

完整冒险按 1–1 到 5–10 推进，包含单行入门、植物奖励、选卡、夜间蘑菇与墓碑、六行泳池、迷雾与屋顶花盆等规则。冒险初始六卡槽，商店可升级；保龄球、打僵尸、砸罐子、雷雨之夜和传送带关使用各自规则。普通、困难和无尽生存按场景保存。可用鼠标或触屏选卡、种植、铲除和收集阳光。

阳光收集器为永久道具，首次通关赠送；到达第1–3关后也可用150游戏金币购买。主菜单「阳光道具」进入，拥有后可在战场开关。五关版已有的拥有/启用状态会保留；旧金币一次性导入完整冒险，之后两种玩法分别保存金币和关卡进度。旧挑战通关不会伪造完整冒险的通关记录。永久拥有状态另存为不可被旧存档降级的标志；旧页面写回存档也不会丢道具。两种玩法在存档变化事件中同步道具，购买前重新核对拥有状态，避免重复扣款。

音乐与音效首次交互后开启，可单独关闭。音乐用一个原生音频元素流式播放，避免把整首音乐展开为大块PCM内存；音效最多12路并发，普通射击/命中最多占10路，为波次等提示留出空间。通用射击与普通命中使用可追溯的经典录音及原有变体权重，新增五段素材合计30.2 KiB，复用解码缓冲；铁桶/路障、火球、玉米、黄油和西瓜按命中类型分层播放，额外专用素材合计56.2 KiB，按关加载。画面准备好即可开局，不等待全部音效下载；音效失败不会卡住开始或继续按钮，后续操作可重试加载。暂停、后台和菜单停止战斗绘制，资源在后台加载完成也不会自行启动战斗。

## 渲染和加载

完整冒险最高30 FPS，规则模拟仍为固定10毫秒步长。普通场景背景恢复到原生1400×600，相对白天关原来的两张2倍背景，RGBA纹理理论用量减少约20 MB；手机菜单使用普通尺寸背景。绘制像素预算不超过800×600，不随高DPR手机或大显示器放大；关闭多重采样，使用部件图集、批量绘制和按关加载，切换关卡释放前一战场资源。静止菜单不启动战场循环，暂停和结算停止循环。电脑与手机横屏均使用经典顶部卡槽，六张常用卡同时可见；手机铲子、速度和菜单按钮保留至少44像素的点击尺寸。

植物、僵尸、巨人和僵王的134张运行纹理改用固定源版本的经典原尺寸像素，无损打包并沿用相同的动作和帧矩形坐标。这批图片的单份RGBA解码估算从110.9 MB降至27.7 MB，文件从5.66 MB降至3.25 MB。相同本机场景中，僵王关持有纹理的单份RGBA估算从86.8 MB降至34.3 MB；这是纹理估算，不是浏览器总内存或真实手机实测。原始像素、源文件和生成文件哈希见 `classic-adventure/docs/classic-texture-assets.json`。

发布包包含一代运行资源、音乐和旧版本兼容文件，不会在首屏一次性下载。二代内容与原始创作PNG不打包。旧烘焙动画页及已替换的2倍纹理继续保留在服务器，供已打开的旧页面使用，新版离线缓存不下载它们。离线缓存由玩家主动选择下载，首次只缓存启动文件。每个完整发布版本使用独立的离线服务文件，旧地址继续兼容；在线刷新优先获取新首页，网络停滞3秒或出错时回退到已安装的离线首页，不覆盖旧首页与素材的配对。

浏览器中已渲染白天、夜晚、泳池、迷雾、屋顶及其专属植物和僵尸。旧百僵尸检查未通过合法种植启动实际战斗，因此此前约0.62毫秒/帧的数据不能作为完整战斗性能依据。检查页现已补上战斗启动和射击、命中、移动的自检：屋顶百僵尸、300次渲染与900个逻辑步中，本机桌面和390×844视口分别约1.825和1.893毫秒/帧；两者同为12次射击、12次命中、489个投掷物活跃逻辑步，画布分别为800×600和390×293。记录见 `output/重力投掷-桌面压力测量.json` 和 `output/重力投掷-手机尺寸压力测量.json`；这是本机同步CPU循环与提交绘制测量，不是真实手机CPU、GPU、实时帧率或功耗证明。
