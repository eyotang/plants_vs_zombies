# 后院守卫战 · 阳光旧时光

浏览器草坪塔防，原创绘制角色，致敬经典植物大战僵尸。无依赖、无远程资源，直接打开 index.html 即可离线游戏，或运行 `python3 -m http.server 8080` 后访问 http://localhost:8080。

- 六种植物：阳光花、豆豆射手、坚果墙、寒冰射手、双发射手、樱桃炸弹。
- 经典冒险：抵挡五波；无尽生存：波次持续加强。每波清场奖励 75 阳光。
- 点卡牌再点草坪，点阳光收集；1–6 选卡，S 铲子，Esc 取消，空格暂停。
- 切至后台自动暂停，点击继续恢复；音效可关闭。

先种两三株阳光花，再按僵尸所在行部署射手。坚果拖延时间，寒冰控制推进速度，樱桃留给拥挤的防线。

## 性能与验证

Canvas 2D，固定最高 30 FPS，缓存背景与角色绘制，界面数据每秒最多更新十次，暂停时停止动画循环。无游戏引擎、下载库或联网请求。最高纪录保存在当前浏览器本地。

`node --check game.js` 检查语法。打开游戏后把 `tests/battle-check.js` 粘贴到浏览器控制台，可验证扣费、暂停、寒冰减速、炸弹、割草机、失败、通关、无尽与满草坪压力场景。测试会重置对局。
