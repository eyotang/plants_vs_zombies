# 植物大战僵尸 · 本地经典版

使用现有经典素材制作的浏览器游戏，无需登录。包含50关冒险、白天/夜晚/泳池/迷雾/屋顶、特殊关和僵王战，以及普通、困难和无尽生存模式。金币与进度保存在当前浏览器。

## 开始游戏

在线入口：[WorkBuddy 原分享链接](https://plants-vs-zombies.apps.workbuddy.host/?sharecode=FR6B3XZMIS)。线上版本以发布回执和文件校验为准。

Mac本地运行：解压 `output/植物大战僵尸-本地经典版.zip` 后，双击「本地启动.command」。关闭启动窗口即停止本地服务；需要系统中有Python3。其他电脑可用静态网站服务打开 `dist/`，入口为 `dist/index.html`。完整冒险需要通过本地服务打开；源码根目录 `index.html` 为保留的五关参考挑战。

鼠标或触屏选卡、种植、收集阳光，使用铲子移除植物。手机建议横屏。暂停菜单可以分别开关音乐、音效和血条，切换画面比例。音乐首次交互后开启。

阳光收集器首次通关永久赠送，也可在第1–3关解锁后用150游戏金币购买。主菜单「阳光道具」进入，拥有后可在战场开关；不涉及付款。已有道具拥有状态独立保存，避免旧存档写回时丢失。

## 画面与资源

沿用现有经典植物、僵尸、庭院、阳光和铲子素材，补齐经典音乐与命中音效。完整冒险主要参考 xyxiao001/pvz-web 的一代实现、Portable对照资料和固定版本的原版资源；用户提供的 PythonPlantsVsZombies 是五关参考版的主要来源。未混用 Cataclysm-DDA 素材。来源、修改与授权声明见 `THIRD_PARTY_NOTICES.md`、`classic-adventure/UPSTREAM.md` 及 `classic-adventure/docs/`。

当前版进一步校正了投掷轨迹与碰撞、地面身体与啃咬矩形、窝瓜和跳跳动作、冻结判定、花盆/睡莲新种保护，以及车辆受压触发。樱桃爆炸和冻结冰块使用可追溯的经典小图。仍有未映射的非投手发射点、特殊动作和粒子效果，不能据此声称逐像素或全部规则1:1完成。

植物被碾压后按原版规则保留约5秒的压扁形态，暂停与存档保留倒计时；采用现有图集生成的小型静态贴图，过期或退出场景时释放，并补上两段经典碾压声。核对范围与剩余差异见 `classic-adventure/docs/native-squish.json`，本机证据见 `output/压扁形态-优化验证.json`。

普通植物的基础根坐标与缩放已统一到原版网格，补齐种类高度、花盆支撑、水面浮动及土豆雷/咖啡豆缩放。校准场景的12种植物在屋顶上原有最多约33像素偏差，修正后与源公式对齐；这不代表所有动画或发射口已1:1。证据见 `output/植物原生根坐标-优化验证.json`。

## 加载与性能

战斗绘制最高30帧，规则以固定10毫秒步长运行。绘制像素预算最多800×600，不随高DPR设备放大；关闭多重采样，按关加载和释放战场资源，暂停、后台和菜单停止战斗循环。

134张角色运行纹理采用经典原尺寸像素，无损打包。单份RGBA理论用量从110.9MB降至27.7MB，文件从5.66MB降至3.25MB。相同本机场景中僵王关纹理理论用量从86.8MB降至34.3MB；这些是纹理估算，不能代表浏览器总内存或真机表现。

标题图按屏幕宽度和密度选择现有1400/2800像素版本。已验证的手机三倍密度和桌面两倍密度场景中，标题图文件从1352008降至343504字节，减少约74.6%；大屏三倍密度仍使用高清版本。菜单背景预加载与实际选择对齐，桌面不再额外请求156070字节的普通背景。这是单项资源减少，不代表完整首屏提速或真机总内存下降；检查见 `output/首屏图片-优化验证.json`。

已修正Safari高密度屏幕中卡槽太阳被压窄、数字看似偏出纸条的问题，复用同一张图片，不新增运行资源。Safari与Chrome的同图比例对照及844×390尺寸检查见 `output/HUD比例-优化验证.json`；这不是实体手机或整套界面逐像素验收。

音效缓存按当前关卡保留，返回菜单或重开时释放并挂起音效引擎，取消旧请求且忽略晚到的解码。桌面Safari受控卡组切回第一关时，应用持有的PCM数据从14693648降至9666844字节，返回菜单后为0；这不是浏览器总内存。真实菜单两次往返的复用与播放检查见 `output/音效生命周期-优化验证.json`。

音乐使用一个原生音频元素流式播放；音效最多12路并发，其中两路为提示保留。画面准备好即可开局，不等待全部音效。离线资源仅在玩家主动选择后下载，首次只缓存启动文件。每个版本使用独立离线服务地址，发布时保留上一代脚本兼容地址。

已完成本机电脑、390×844与844×390视口的受控画面和操作检查。真实iOS/Android的CPU、内存、功耗和逐关触控体验尚未完成实测。历史CPU测量的范围和限制保存在对应的 `output/` 记录中，不作为当前真机性能保证。
